# Penetration Testing Lab Reports

This repository contains detailed penetration testing reports for intentionally vulnerable lab machines inspired by Hack The Box (HTB) and CTF-style environments.

Each report follows a structured penetration testing methodology, focusing on real-world attack chains rather than simple walkthroughs.

---

## 📌 Objectives

- Practice end-to-end penetration testing methodology
- Improve enumeration and exploitation skills
- Gain hands-on experience with privilege escalation techniques
- Build professional-grade documentation for portfolio and interview discussions

---

## 🧪 Methodology

Each machine is tested using a standard penetration testing lifecycle:

1. Reconnaissance
2. Scanning & Enumeration
3. Vulnerability Identification
4. Exploitation
5. Post-Exploitation
6. Privilege Escalation (linpeas, pspy, manual analysis)
7. Documentation & Reporting
